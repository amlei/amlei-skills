# 如何录制一档音质合格的播客？

你有没有听过一些播客，内容精彩，但背景噪音大、声音模糊、音量忽大忽小，让你很难坚持听下去？

研究和听众反馈表明，糟糕的音质是听众流失的主要原因之一，本期让我们来**根据不同录制场景，选择最适合、最经济的方案，迈出播客录制的第一步。**



### 理解“音质合格”

- “音质合格”不代表一定要是“录音棚级别”，合格不等于昂贵，我们的目标是“​清晰、干净、稳定​”。
- 三个关键指标具体表现为：​

  - 清晰：​人声饱满，没有模糊感。
  - 干净：​背景噪音小，没有回音和刺耳的杂音。
  - 稳定：​音量一致，不会突然变大变小。



### 录音环境条件​

**原则：​ 创造“小、静、软”的室内空间。**

实操建议：​

- 小：​最好在室内录制，选择小房间（如书房、会客室、衣帽间）比空旷的大客厅效果更好。
- 静：关闭空调、风扇、洗衣机等容易发出噪音的电器，手机调至静音，避免穿着容易摩擦发出声音的衣物，选择环境噪音最小的时段录制。
- 软：拉上房间窗帘、铺上地毯、放几个抱枕或者打开衣柜，吸收反射声，避免回音。

### 入门尝试——手机录制指南

在决定正式投入前，先用最小的成本和便捷的工具验证你的内容想法和表达欲，是一个非常合理的思路。所以本章我们将说明，如何用手机录出“尽可能好”的声音。

- **关键设置：​​**

  - **手机设置：**在保证上述“小、静、软”的室内空间录音环境之外，最好将手机调至“飞行模式”，避免录音过程中的电话、通知铃声干扰。
  - **正确放置：**手机必须放在稳定的表面（桌面或者一摞书上），使用手机支架最佳，避免任何手持摩擦噪音。
  - **姿势与距离：**手机放在面前，麦克风（通常在手机底部）对准嘴巴，距离约20-30厘米，避免身体与手机的距离变动。
  - **录音软件设置：**若使用原生“语音备忘录”，需在设置中将录制模式设置为“单声道”，“音频质量”设置为“无损”（下图1）。若使用其他更为专业的录音App：​ 如Saramonic（下图2）、Motive Audio（下图3）等，需确保录制选项设置如图所示，以保证声音录制质量。
  - **测试与监听：**在正式开始录制前，最好录制30s的测试音频，并戴上耳机进行回放监听，确保没有异常杂音。

- **手机录音的进阶技巧：​​**

  - **使用领夹麦克风：**​若环境噪音较大，可连接一个有线或蓝牙领夹麦克风，将麦克风固定在衣领，距离声源更近，能极大减少环境噪音，声音更清晰饱满。同样，在正式录制前可以录制30s的测试音频，以保证麦克风连接稳定，声音无异常。



### 正式创作——专业设备入门

当你从听众那里获得了足够的正反馈，决定更认真地对待播客创作时，投资一套入门级专业设备将让你的音质和创作体验产生质的飞跃。

#### 场景及设备选择

- **方案一：单人室内固定场景录制**

  - 设备：USB麦克风，通过USB线直接连接电脑进行录音。
  - 推荐型号：​ RODE NT-USB / 铁三角ATR2500X-USB等。
  - 优点：​即插即用，设置简单，无需额外设备，性价比高。
- **方案二：单人/双人室内外灵活场景录制**

  - 设备：XLR麦克风 + 录音笔，将XLR接口的专业麦克风直接连接到便携式录音笔上进行录音。
  - 推荐型号：舒尔SM58 / 罗德PodMic + Zoom H5/H6 / Tascam DR-40X。
  - 优点：可移动，在任何地方进行录音。完全脱离电脑，杜绝电脑死机、软件崩溃导致的数据丢失。
- **方案三：多人室内固定场景录制**

  - 设备：XLR麦克风 + 音频接口，通过XLR线连接到音频接口，再由接口连接电脑进行录音。
  - 推荐型号：​ 舒尔SM58 / 罗德PodMic + 罗德Caster Pro II/Focusrite Scarlett 2i2 等入门级音频接口。
  - 优点：​更专业、扩展性更强的组合。音质上限更高，接口可连接更多麦克风。
- **配件可选：​**

  - 监听耳机：实时掌握录音质量，方便及时调整。
  - 防喷罩：​ 有效消除“噗噗”的喷麦声。
  - 支架：​ 稳固的桌面支架或悬臂支架，避免手持噪音。

#### 录音软件及设置

- **软件选择：**

  - **单人录制：**可直接使用电脑自带的录音软件，如“语音备忘录”“Windows录音机”。
  - **双人/多人录制：**库乐队、Adobe Audition、Studio One等多轨录制软件。
- **软件设置：**

  - 播放设备： 选择你的监听耳机。
  - 录制设备： 选择你的麦克风或音频接口。
  - 声道： 选择单声道。
  - 采样率： 设置为 44100 Hz 或 48000 Hz，与你的设备设置保持一致。
- **录音前的检查：​​**

  - 在音轨上，点击红色的“录音准备”按钮，此时你对着麦克风说话，应该能看到电平表在跳动。
  - 再次检查电平！ 确保峰值在 -12dB 到 -6dB 之间。如果过高或过低，去调整物理设备（音频接口或麦克风）上的增益旋钮，而不是软件里的音量滑块。

#### 录音习惯

- 距离：​ 嘴巴距离麦克风约一拳，保持距离稳定。
- 角度：​ 稍微偏离麦克风正中心，可以减少气流冲击。
- 电平（音量）：​ 在录音软件中，观察音量表，让峰值在 -12dB 到 -6dB 之间（​在绿灯到黄灯区间，不要冲上红灯），这是留给后期处理的“安全余量”。



### 特殊场景录制指南

#### 双人/多人同场录制

-  场景特点：多位参与者在同一空间，核心挑战是避免主讲人之间的串音，并确保每个人的音质清晰、音量平衡，为后期处理保留最大的灵活性。
- **方案一（推荐）：双设备录制法**

  - **适用设备：**两部手机或两个麦克风连接便携式录音笔
  - **设备设置：**可参考上述手机录制指南和专业设备入门方案为每一位主讲人进行设置。若使用麦克风，则将两支麦克风分别接入设备的两个输入口，即可录制两条独立的音轨。
  - **特点：**音质优秀，后期灵活，需注意不同音轨之间的对齐。
- **方案二（备选）：单设备共享录制法**

  - **适用设备：** 一支支持全指向或立体声模式的USB麦克风或一支高质量的便携录音笔。
  - **设备设置：** 将麦克风设置为全指向/环绕指向模式，并将其放置在桌面或支架的中央，确保所有参与者与麦克风的距离大致相等。
  - **后期调整：**录制完成后，你会得到一个立体声文件，其中某位参与者可能偏左声道，另一位的声音可能偏右声道。在软件中，可以将这个立体声文件分离成两条单声道音轨，然后对每条音轨进行独立的音量调整和降噪。
  - **特点：**参与者距离麦克风较远，声音的清晰度和饱满度会下降，全指向收录声音环境噪音会更明显。

#### 双人/多人远程录制

- 场景特点：​ 嘉宾的录音设备水平不一致，过程中难以灵活调整，较难控制，最好让每一位嘉宾都能在录制过程中单独进行​ ​​“本地录音”。
- **最佳方案：​ ​双轨录音法**（保证每个参与者都有高质量的独立音轨，解决网络波动和压缩音质问题）

  - 步骤1：​ 使用腾讯会议 / Zoom等会议软件，通过耳机进行通话，避免干扰收音。（会议软件在线录制的声音可作为备份，尽量不要直接使用）
  - 步骤2：​ 要求每位参与者用另外一个设备单独录制一份无损的干声，可以在开始时约定一个打板口号，方便后期音轨对齐。（参考上面提到的录制方案，根据各自设备情况选择）
  - 步骤3：​ 录制结束后，大家将各自的干声音频文件发给节目制作人进行后期合成。
